## Project Name:  💪 BD Market Price

## 📅 Short Description:
BD Market Price is a web application that helps users explore product prices in Bangladesh through category-wise browsing, responsive product cards, and detailed product pages. Built with Next.js, TypeScript, Tailwind CSS, and REST API integration, it includes price sorting with Bengali numeral support and Better Auth integration to restrict access to product details to signed-in users.

## Technologies used 
. React
. TypeScrip
. Tailwindcss
. Better Auth Authentication 
. Next.js

## Five key features of the project

1. Category-wise Product Browsing – Explore products by different market categories in Bangladesh.
2. Product Details – View detailed product information and market prices.
3. Authentication & Protected Routes – Restrict access to product details for signed-in users.
4. Price Sorting – Sort products by price from low to high or high to low.
5. Responsive UI & API Integration – Browse products on different devices with real-time data fetched from an API.
